# 靠近 · 依恋类型自测

一个无需构建工具、直接在浏览器中运行的成人依恋双轴自测页面。

## 使用

直接打开 `index.html`，或用任意静态文件服务器托管整个目录。

## 功能

- 28 道题，焦虑与回避两个维度各 14 题
- 反向计分、四象限结果、临界值与居中/混合倾向提示
- 双轴位置图、趋势条和分类型建议
- 四种依恋科普、量表说明和隐私声明
- 本地 Canvas 生成结果分享图，不上传答题数据
- 手机优先布局、键盘操作、减少动态效果适配

## 说明

本测试基于成人依恋双维模型设计，不是 AAI、ECR 或 ECR-R 的官方中文版本，也未建立临床常模。结果仅用于科普与自我觉察，不能替代心理咨询或专业评估。
